# 中文合同检索冒烟语料

`zh_contract_smoke_v1.json` 是项目自编的合成中文商业合同条款集，包含 32 条短条款和 24 个问题，覆盖付款、期限、续约、验收、责任、保密、争议解决、解除八类意图。每个问题的 `relevant_ids` 为人工指定的预期条款；其余条款在本次封闭冒烟集里按不相关处理。

此文件不包含用户上传合同或真实当事人信息，也不代表自然合同的长度、歧义、扫描质量和行业分布。它仅用于发现检索接线、中文分词和排序问题。修改条款或答案时应更换数据版本，并保留旧报告的语料 SHA-256。真实质量评测需另外收集有授权、已脱敏的完整合同，由人工标注证据位置与可接受答案。
